  <h2>📝 Description</h2>
  <p>The <strong>HR Analytics</strong> project is a comprehensive Human Resources analytics solution designed to provide actionable insights into workforce data. This project combines SQL-based data processing with an interactive Power BI dashboard to help HR professionals and business leaders make data-driven decisions about:</p>
  <ul>
    <li>Employee attrition rates and retention metrics</li>
    <li>Departmental performance analysis</li>
    <li>Compensation and salary trends</li>
    <li>Employee demographics and diversity metrics</li>
    <li>Turnover analysis and predictive insights</li>
    <li>Performance ratings and productivity metrics</li>
  </ul>
  <p>The project enables HR departments to identify patterns, predict potential issues, and optimize workforce planning strategies.</p>

  <h2>✨ Features</h2>
  <ul>
    <li><strong>SQL Database Integration</strong> — Structured data queries and analysis using SQL</li>
    <li><strong>Interactive Dashboard</strong> — Visual representation of key HR metrics using Power BI</li>
    <li><strong>Real-time Analytics</strong> — Up-to-date workforce insights and KPIs</li>
    <li><strong>Attrition Analysis</strong> — Track and predict employee turnover</li>
    <li><strong>Department Insights</strong> — Department-wise performance and staffing analysis</li>
    <li><strong>Compensation Analysis</strong> — Salary trends and compensation insights</li>
    <li><strong>Employee Demographics</strong> — Detailed employee categorization and statistics</li>
  </ul>

  <h2>⚒️ Stack</h2>
